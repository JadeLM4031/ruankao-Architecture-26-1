📐ATAM 架构评估核心概念

六个关键概念（必背）

概念 标准定义 判断关键词
敏感点 一个架构决策影响一个质量属性 只涉及1个质量属性，影响显著
权衡点 一个架构决策影响多个质量属性（此升彼降） 涉及≥2个质量属性
风险 架构决策存在潜在负面结果 "团队能力不足""经验欠缺""可能成为瓶颈"

敏感点 vs 风险陷阱："主库写入可能成为瓶颈"看似风险，但它分析的是对性能这一个属性的影响 → 是敏感点。"团队能力不足"这种组织层面不确定因素才是风险。

🔗区块链核心概念

四大核心概念

概念 说明
链式哈希结构 每个区块包含前一区块的哈希值，保证不可篡改
智能合约 链上自动执行的代码，满足条件自动触发（如以太坊Solidity）
共识机制 分布式节点达成一致的算法
去中心化 无中心化服务器，P2P网络，节点对等

六层模型（案例必背）

层级 名称 功能说明
1 数据层 底层数据结构，包括区块（区块头+区块体）、链式结构（前块哈希）、哈希函数（如SHA-256）、默克尔树（交易摘要）
2 网络层 P2P点对点网络，节点发现与通信，交易广播和区块传播机制，Gossip协议
3 共识层 让分布式节点对账本达成一致的算法：PoW（工作量证明）、PoS（权益证明）、DPoS（委托权益证明）、PBFT（实用拜占庭容错）
4 激励层 经济激励机制，发行代币/积分，奖励出块节点，鼓励诚实行为，惩罚恶意行为
5 合约层 智能合约的部署和执行环境，脚本代码、虚拟机（如EVM），实现业务逻辑自动化
6 应用层 面向用户的DApp（去中心化应用），如数字货币、供应链溯源、数字身份、NFT、DeFi
六层速记：数 网 共 激 合 应（数据层→网络层→共识层→激励层→合约层→应用层）

智能合约详解（案例300字答题模板）

智能合约是部署在区块链上的可自动执行的程序代码，由以太坊首次提出并实现。它以"如果-那么"的逻辑形式定义交易规则，当预设条件被满足时，合约自动触发执行，无需第三方中介干预。

核心特征：
（1）自动执行：条件满足即触发，无需人工干预；
（2）不可篡改：部署后代码无法修改，运行结果确定；
（3）透明公开：代码在链上可验证、可审计；
（4）去信任：不依赖第三方，由代码逻辑保证执行。

开发语言：Solidity（以太坊）、Move（Diem）等。
运行环境：EVM（以太坊虚拟机）等链上虚拟机。
应用场景：数字资产交易、供应链自动结算、保险自动理赔、DeFi借贷协议。

区块链工作流程（案例必背）

  1. 用户发起交易：用户通过钱包客户端创建一笔交易，用私钥签名
  2. 交易广播：交易通过P2P网络广播到全网节点
  3. 节点验证：各节点收到交易后验证签名有效性、余额是否充足、格式是否合法
  4. 打包进区块：矿工/验证节点将验证通过的交易打包成候选区块
  5. 共识竞争：节点通过共识机制（如PoW算力竞争、PoS权益投票）竞争出块权
  6. 区块广播与验证：获胜节点将新区块广播到全网，其他节点验证区块合法性
  7. 追加到链上：验证通过后，新区块追加到区块链末尾，交易被确认
  8. 全网同步：所有节点更新本地账本副本，达成一致性状态
流程速记：发起 → 广播 → 验证 → 打包 → 共识 → 上链 → 同步

共识机制对比

PoW（工作量证明）
算力竞争出块
✅ 安全性高
❌ 耗能大、速度慢
代表：比特币
PoS（权益证明）
持币量决定出块权
✅ 节能、速度快
❌ 需质押、富者愈富
代表：以太坊2.0

安全风险

  • 51%攻击：控制超过半数算力可篡改交易
  • 智能合约漏洞：代码漏洞导致资金损失（如DAO事件）
  • 私钥丢失：无法找回，资产永久丢失
案例答题关键词：不可篡改、可追溯、去中心化、共识机制、智能合约。遇到区块链题至少写出这五个。

📄LRU / FIFO / OPT 页面置换

LRU 手算方法

维护列表：左边=最近使用的，右边=最久没用的。命中→移到最左；缺页→淘汰最右，新页加最左。

三种算法对比

算法 淘汰策略 Belady异常
OPT 淘汰将来最久不用的（向后看） 不会
LRU 淘汰过去最近最久未用的（向前看） 不会
FIFO 淘汰最早进入的 可能
Belady异常 = 增加页框数反而缺页率上升。只有FIFO可能出现。LRU和OPT是栈式算法，不会。

缺页率公式

缺页率 = 缺页次数 / 总访问次数

快速判断技巧

  • 前N次访问（N=页框数）必为缺页（初始为空）
  • 刚被淘汰的页面如果马上又被访问，一定缺页
  • 序列中有连续重复的页号 → 命中机会多

🔄PV 操作

基本规则

P(S)：S=S-1，若S<0则阻塞等待  |  V(S)：S=S+1，若有等待进程则唤醒
P = 申请等待  |  V = 释放通知

生产者-消费者

缓冲区容量N。empty=N, full=0, mutex=1：

生产者：P(empty) → P(mutex) → 写 → V(mutex) → V(full)
消费者：P(full) → P(mutex) → 读 → V(mutex) → V(empty)
P的顺序不能反（先P(empty)再P(mutex)，否则死锁）。V的顺序无所谓。N=1时可省略mutex。

多读者-写者

读者：P(mutex); rc++; if(rc==1)P(rw); V(mutex); 读; P(mutex); rc--; if(rc==0)V(rw); V(mutex)
写者：P(rw); 写; V(rw)

前趋同步

P1先完成：V(S)  |  P2后开始：P(S)  |  信号量S=0

做题三问

  1. 谁等谁？ → 先完成的V，后开始的P
  2. 有没有互斥？ → 共享资源需要mutex
  3. 信号量初始值？ → 一般题目会给出

⚡流水线计算

三个核心公式

时钟周期：Δt = max(各段时间)
总时间：T = (级数k + 指令数n - 1) × Δt
吞吐率：TP = n / T  |  加速比：S = 不用流水线时间 / T

计算示例

4级流水线，各段2ns/3ns/2ns/2ns，100条指令：

  • Δt = max(2,3,2,2) = 3ns
  • T = (4+100-1)×3 = 103×3 = 309ns
  • TP = 100/309 ns⁻¹
  • 不用流水线：每条9ns×100=900ns，S=900/309≈2.91

气泡（Stall）

实际时间 = 理想时间 + m×(n-1)×Δt（m=每条指令插入的气泡数）

特征 RISC CISC

死锁资源计算

m ≥ n×(X-1) + 1

m=资源总数，n=进程数，X=每个进程最多需要的资源数

含义：最坏情况每个进程各拿(X-1)个（差1个就能完成），再留至少1个给某个进程先完成释放。

💰挣值分析

三个基本量

符号 名称 含义
PV 计划值 到某时点计划完成的工作预算
EV 挣值 到某时点实际完成的工作预算
AC 实际成本 到某时点实际花费

四个偏差指标

CV = EV - AC（成本偏差）>0=节约
SV = EV - PV（进度偏差）>0=超前
CPI = EV / AC（成本绩效指数）>1=节约
SPI = EV / PV（进度绩效指数）>1=超前
EV永远是分子！"偏差"用减法，"指数"用除法

预测公式

BAC = 完工总预算
EAC = BAC / CPI（典型偏差时）
ETC = EAC - AC（还需花多少）
VAC = BAC - EAC（完工偏差）

🗺️关键路径

关键路径 = 从起点到终点最长的路径 = 项目最短完成时间

总时差

总时差 = 最迟开始LS - 最早开始ES
总时差=0的活动 = 关键活动。关键活动连起来 = 关键路径。

做题方法

  1. 列举路径法（小项目）：画出所有路径，最长的是关键路径
  2. ES/LS法（给了表格）：找总时差=0的活动，连成路径

易错点

  • 关键路径不一定只有一条
  • 关键活动delay一天 = 项目晚一天
  • 非关键活动的总时差 = 可以拖延而不影响总工期的天数

🔐加密与数字签名

对称 vs 非对称加密

对称加密
同一把密钥加解密
✅ 速度快
❌ 密钥分发困难
代表：AES、DES、3DES
非对称加密
公钥加密、私钥解密
✅ 解决密钥分发
❌ 速度慢
代表：RSA、ECC

数字签名完整流程

  1. 发送方对消息做哈希（摘要）
  2. 用发送方的私钥加密摘要 → 签名
  3. 用接收方的公钥加密消息 → 保密
  4. 接收方用自己的私钥解密消息
  5. 用发送方的公钥解密签名 → 验证
  6. 对消息做哈希，与解密的摘要对比
先哈希再签名（不直接签名原文，签名摘要）。签名=私钥加密摘要，验证=公钥解密摘要。

密码存储

密码存储用加盐哈希（Salt+Hash），不是加密！加密可逆，哈希不可逆。

扩展性/可修改性问法答题模板

① 定义标准接口（接口层抽象）
② 采用注册机制（插件注册发现）
③ 使用配置化/规则化方式（声明式扩展）
④ 具体技术：SPI机制、策略模式、观察者模式

案例三步法

  1. 结论：直接回答问题
  2. 具体技术名词+原理：用专业术语，不用通俗描述
  3. 逐条对应背景条件：把题目中的条件逐条回应（值2-3分）
常见失分原因：只写关键词不展开、不用专业术语、不对应题目背景条件。

分页地址转换公式

页号 = 逻辑地址 / 页面大小（整除）
页内偏移 = 逻辑地址 % 页面大小
物理地址 = 页框号 × 页面大小 + 页内偏移

页面4KB时十六进制快速法：页号=高位部分（去掉末3位hex），偏移=末3位hex
