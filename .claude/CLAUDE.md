# 项目工作规则（Claude必读）

> 本文件随仓库走。任何新会话/新电脑上的Claude，先读完本文件再开工。

## 用户背景
- 备考**软考高级·系统架构设计师**，2026-10-24考试（下半年批次）
- 成绩史：2025下 选择47✅/案例43❌/论文48✅；2026上 选择41❌/案例51✅/论文37❌——**三科各过过线，问题是同场全过**（各科≥45）
- 优先级（2026下冲刺定论）：论文 > 选择 > 案例
- 用户时间不固定（碎片化，只有晚上1-2h），敢质疑、要求证据，讨论考情必须给来源

## 工作方式铁律（多次纠正后的定论，违反=返工）
1. **计划永远过关式（checkpoint），绝不按日期/周几排**——完成一关直接进下一关
2. **练习题一律做进 quiz.html**，不在对话里出题。页面规范：亮色主题、选择提交前可改/提交后锁定、**localStorage自动保存进度**（每卷独立key）+清空重来按钮、做完生成报告一键复制
3. **计算题答案必须双遍验证**（人工逐行推演+脚本模拟一致才发布），零容忍
4. **出题三条铁律**：对标真题难度、题型分布仿真、模拟分要接近实考分。干扰项**禁止稻草人化**——用真题干扰技术：镜像对调/半真半假/特征互换/场景约束二选一/张冠李戴/否定式
5. **不考的内容绝不写入文件**；进文件的知识必须有真题证据；框架API细节等面试层次内容只放对话，不进文件
6. **用户背的教材原文级定义（如ATAM敏感点/权衡点）是对的**——不要用转述去"纠正"，要改先查教材原文
7. 用户自评不熟的知识点按"没学"处理，即使历史记录显示练过

## 文件地图（Summary.html = 唯一主战场）
- **Summary.html**：考生唯一使用入口，30个章节（架构风格/案例话术/速记版/论文模板/出题记录/AI大模型/冲刺急救卡/考前几页纸等）。**论文相关更新必须同步进s22**；用户不看md文件（视为工作副本）
- **quiz.html**：当前关卡答题页（每次覆盖，独立localStorage key）
- **论文模板_无人机平台.md / 论文AI主线素材包.md**：Claude的工作副本，用户不直接用
- **3_错题与复盘/**：每关测试记录（测试14~18含复盘）
- 表格样式规则（用户反复调过的定稿）：所有表格自动包.tbl-scroll横滚容器（表内滚、页面不滚）；单元格按视觉宽度计（汉字=1、半角=0.5）超20字折行否则单行；JS内联样式实现
- **考前几页纸PDF**：希赛资料，加密+图片型，无法程序提取文本；已做iframe预览页（s30，默认下半年可切换），需随仓库推送才能在手机GitHub Pages上预览；**考后建议从公开仓库删除（版权）**

## 论文规则（2026上37分教训的定论）
- 项目：输电无人机智能管控平台，**2025年6月立项→2026年4月上线→运行约半年**（勿与考试年份混淆）
- 打法：**题目绑定式**——第二问枚举清单=评分标准，逐项编号成段；摘要≤300字含RAG+向量数据库+管线+三个效果数字（九成初筛/分钟级/约60%）
- 主线：AI（RAG族）第一 + 高并发六方面（缓存异步限流降，库优拆分再扩容）第二 + 模块B候补 + 保底
- 4选1决策法：扫各题第二问枚举清单数覆盖度，选覆盖最高（≥60%）的
- **绝不换项目**；换方向=换主角子系统+换主线词
- 白话+术语锚：句子可以白话，术语必须原样出现
